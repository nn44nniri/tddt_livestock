# Generated end-of-cycle outputs

این پوشه برای خروجی‌های تولیدی `run_growth_endOf_cycle.py` استفاده می‌شود. خروجی‌های قدیمی نسخه قبل حذف شده‌اند تا فایل‌های CSV/HTML/JSON با پیکربندی قدیمی Holstein (`milk_available_a=18.0`) داخل بسته باقی نمانند.

پس از اجرای اسکریپت، فایل‌هایی مانند `growth_optimizer_outputs_case_<case_id>.csv` دوباره با پیکربندی اصلاح‌شده ایجاد می‌شوند.
