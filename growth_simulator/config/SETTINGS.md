# LiGAPS-Beef calibration settings

این سند متغیرهای کالیبراسیون منتقل‌شده به `config/settings.json` را توضیح می‌دهد. کتابخانه قبل از شبیه‌سازی فایل JSON را می‌خواند و مقدارهای hard-coded قبلی را از آن دریافت می‌کند.

## runtime

گزینه‌های اجرایی و اشکال‌زدایی.

- `default_case_ids`: مقدار قابل تنظیم؛ مقدار فعلی `[1, 3, 5, 7, 9, 10]`.
- `show_progress`: مقدار قابل تنظیم؛ مقدار فعلی `False`.
- `progress_leave_outer`: مقدار قابل تنظیم؛ مقدار فعلی `True`.
- `progress_leave_inner`: مقدار قابل تنظیم؛ مقدار فعلی `False`.
- `progress_mininterval`: مقدار قابل تنظیم؛ مقدار فعلی `0.5`.
- `debug_loop`: مقدار قابل تنظیم؛ مقدار فعلی `False`.
- `debug_cases`: مقدار قابل تنظیم؛ مقدار فعلی `[1, 3, 5, 7, 9, 10]`.
- `debug_i`: مقدار قابل تنظیم؛ مقدار فعلی `None`.
- `debug_j`: مقدار قابل تنظیم؛ مقدار فعلی `None`.
- `debug_max_iter`: مقدار قابل تنظیم؛ مقدار فعلی `200`.

## case_definitions

تعریف caseهای مقاله و سناریوهای قابل کالیبراسیون.

- `genotype`: کد نژاد برای هر case؛ 1=Charolais، 4=3/4 Brahman×1/4 Shorthorn.
- `slaughter_weight_males_kg`: وزن کشتار گوساله نر برای هر case بر حسب kg.
- `housing_phase1`: وضعیت نگهداری دوره ژانویه تا مارس؛ 0=stable، 1=outdoor.
- `housing_phase2`: وضعیت نگهداری دوره مارس تا دسامبر.
- `housing_phase3`: وضعیت نگهداری دوره دسامبر.
- `feed_availability_1_kg_dm_day`: دسترسی خوراک اول برای هر case بر حسب kg DM/animal/day.
- `feed_availability_2_kg_dm_day`: دسترسی خوراک دوم برای هر case بر حسب kg DM/animal/day.
- `feednr`: شماره جیره هر case؛ 1 تا 5 طبق مدل مرجع.
