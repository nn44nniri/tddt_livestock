3D learning progress report

This report uses a robust 3D scatter/line visualization instead of a surface-only plot. It remains visible even for short runs or sparse offline rebuilds.

Uses learning_daily.csv when available; otherwise reconstructs a compact learning trace from sampled inner-loop telemetry. The Y axis is log1p-scaled so large MPC-cost ranges do not make the 3D report appear blank.
